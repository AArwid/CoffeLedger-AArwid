# CoffeLedger

A decentralized logistics ledger backend for Fair Trade coffee, built with Node.js, Express, and a SHA-256 based Proof of Work system.

## Installation

```bash
npm install
```

## Tests

```bash
npm test
npm run test:watch
```

## Start

```bash
npm start
```

## Development

```bash
npm run dev
```

## TDD commit log

These milestones document the red-green workflow used during development:

- `chore: initialize node project`
- `chore: create application structure`
- `test: specify block hash behavior`
- `feat: implement block hashing`
- `test: specify proof of work mining`
- `feat: implement proof of work mining`
- `test: specify blockchain api endpoints`
- `feat: implement express blockchain api`

These commit messages reflect the project’s test-first development process and can be used as a short change log for the assignment.
